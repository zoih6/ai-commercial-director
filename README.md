# AI COMMERCIAL DIRECTOR — المهارة

مهارة (Skill) جاهزة لأي وكيل ذكاء اصطناعي: تحوّل الوكيل إلى وكالة إعلانات توليدية كاملة.

## الفكرة

المستخدم يرسل أي شيء — جملة، كلام ملخبط، أو صورة منتج — والوكيل:

1. يفهم الطلب داخليًا (التحليل مخفي بالكامل).
2. يرد بإعادة صياغة احترافية + 3 أفكار + 3 أسئلة فقط.
3. بعد اختيار المستخدم: يشغّل فريق وكلاء متخصصين داخليًا.
4. يسلّم حزمة تنفيذية: برومبت صورة مرجعية + برومبتات لقطات + برومبتات مشاهد فيديو + دليل تنفيذ.

## المنهجية

البرومبت هو الخطوة 10 وليس 1:

حقيقة المنتج ← الرغبة ← الفكرة الكبرى ← الاستعارة البصرية ← الهوك ← التصاعد ← اللقطات ← الانتقالات ← البرومبتات ← الجودة

## التركيب

```
ai-commercial-director/
├── SKILL.md            ← العقل التنفيذي (ابدأ من هنا)
├── agents/             ← 10 وكلاء متخصصين
├── workflows/          ← 5 مسارات تشغيل
├── frameworks/         ← 5 أطر منهجية
├── templates/          ← قوالب الردود للمستخدم
└── quality/            ← بوابات الجودة الثلاث
```

## التركيب ك المهارة

1. انسخ مجلد `ai-commercial-director/` كاملًا إلى مكان مهارات الوكيل
   (مثل `~/.claude/skills/` أو ما يقابله في منصتك).
2. تأكد أن الوكيل يقرأ `SKILL.md` أولًا — هو نقطة الدخول الوحيدة.
3. أرسل للوكيل أي طلب، مثل: «أبي إعلان لعطر» أو أرفق صورة منتج مع سطر يشرح ما تريد.

## مبادئ ثابتة

- المستخدم لا يرى التحليل — يرى النتائج فقط.
- 3 أفكار + 3 أسئلة بالضبط في أول رد.
- المنتج الحقيقي يحتاج مرجعًا بصريًا قبل أي توليد (صورة أو Product Sheet بمصادر رسمية).
- لا برومبت واحد لإعلان كامل: مشاهد 2–5 ثوانٍ، لكل مشهد إطار بداية وبرومبت مستقل.
- كل البرومبتات بلغة بشرية وصفية مع قيود واضحة، وجملة تثبيت للمنتج في كل برومبت.
