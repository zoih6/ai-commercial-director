# WORKFLOW — IMAGE ONLY (صور إعلانية ساكنة فقط)

يعمل عندما يريد المستخدم صورًا/بوسترات/منشورات فقط، بلا فيديو.

## متى

- المستخدم قال صراحة: صورة/تصميم/بوستر/منشور/كوفر.
- الطلب حملة ساكنة (عدة صور بفكرة واحدة).

## سلسلة التشغيل الداخلي

| الخطوة | الوكيل | المخرج |
|---|---|---|
| 1 | intent-analyst | BRIEF |
| 2 (متوازيان) | product-intelligence + advertising-strategist | TRUTH + STRATEGY |
| 3 | creative-director | 3 أفكار (discovery) ثم CONCEPT PACK |
| 4 | art-director | VISUAL DNA |
| 5 | image-prompt-specialist | صور الحملة |
| 6 | film-director (نسخة مخففة) | تكوين الصور وتنوعها فقط |
| 7 (متوازيان) | continuity-reviewer + prompt-qa | فحص واعتماد |

## قواعد خاصة بالمسار

1. **حملة لا صور:** إن طلب المستخدم أكثر من صورة، اجعلها مجموعة متنوعة الوظيفة لا الزخرفة:
   - صورة بطل (Hero): المنتج + البيئة الكاملة.
   - صورة تفصيل (Macro): خامة واحدة تقنع بالجودة.
   - صورة فكرة (Concept): الاستعارة البصرية وحدها.
2. كل صورة تحمل الرسالة الواحدة وحدها وتقف بذاتها.
3. الهوية موحدة: نفس اللوحة والضوء عبر كل صور الحملة.
4. نسب الأبعاد حسب المنصات المذكورة في البريف (اذكرها بعد كل برومبت).
5. النصوص (اسم العلامة/السعر/العرض) تُضاف في التصميم النهائي، لا داخل التوليد — إلا بطلب صريح مع تحذير من أخطاء النصوص التوليدية.

## التسليم

وفق `templates/image-output.md`:
- سطر افتتاحي بالفكرة.
- بلوكات البرومبتات مرتبة (مرجع إن لزم → بطل → تفصيل → فكرة...).
- دليل تنفيذ قصير: أي صورة أولًا، ماذا يرفع مع كل برومبت، أين تُضاف النصوص.
