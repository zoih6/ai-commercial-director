# WORKFLOW — FULL COMMERCIAL (الإعلان الكامل)

المسار الافتراضي: من فكرة المستخدم إلى حزمة إعلان كاملة (مرجع + لقطات + مشاهد + دليل).

## الشرط

يعمل بعد: رد الاكتشاف + اختيار المستخدم لفكرة + إجاباته عن الأسئلة الثلاثة.

## سلسلة التشغيل الداخلي

|---|---|---|---|

## قرارات ما قبل التوليد (خذها قبل تشغيل الوكلاء 4–5)

1. **حالة المرجع:**
   - صورة المستخدم كافية؟ → المرجع = صورته، IMG-00 غير مطلوب.
   - لا صور؟ → شغّل `workflows/product-reference.md` وأدخل برومبت المرجع أول الحزمة.
2. **خريطة الصور:** لكل مشهد حدد: Start Frame = أي صورة؟ End Frame مطلوب؟ (الانتقالات الحرجة فقط)
3. **خريطة المشاهد:** قسّم SHOT LIST إلى مشاهد 2–5 ثوانٍ مجموعها = المدة.

## التسليم النهائي

اجمع وفق `templates/video-output.md` (للإعلان الكامل) بهذا الترتيب:

1. سطر افتتاحي: الفكرة المختارة بسطر واحد + الافتراضات المستخدمة (إن وجدت).
2. **A — الصورة المرجعية** (إن لزمت): برومبت + شرح سطر ("أنشئها أولًا واحفظها — هي مرجع كل الخطوات").
3. **B — لقطات الصور (Keyframes):** كل لقطة باسمها وهدفها + برومبت + تعليمات الأبعاد.
4. **C — مشاهد الفيديو:** كل مشهد بمدته + الإطارات المطلوب رفعها + البرومبت في code block.
5. **D — دليل التنفيذ السريع:** 5–8 خطوات مرقمة + ملاحظات مونتاج وصوت (قصيرة).

## قواعد مسار

1. لا تتخطَّ أي وكيل — حتى في الطلبات البسيطة (الخطوات تُنفذ بعمق متناسب مع حجم الطلب، لكن الترتيب ثابت).
2. الافتراضات التي اتخذتها بدل إجابات ناقصة تظهر كسطر واحد فقط في المطلع: "(اعتمدت: 15 ثانية، تيك توك/ريلز، نهاية بشعار العلامة — قل لي لو تبي تعدل)".
3. الناتج يجب أن ينجح حتى لو استخدم المستخدم نموذجًا لا يدعم إطارات البداية: البرومبتات موصوفة ذاتيًا.
4. لا تُغرق المستخدم: الحزمة الكاملة القياسية = 1 مرجع (اختياري) + 4–8 لقطات + 4–8 مشاهد. لو الإعلان أبسط، قلّل. لو طلب تفصيلًا أكثر، زد.
