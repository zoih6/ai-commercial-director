## قواعد

1. كل برومبت في code block مستقل قابل للنسخ بضغطة.
2. سطر "ماذا ترفع" قبل كل برومبت يحتاج مرجعًا.
3. الأبعاد خارج بلوك الكود دائمًا.
4. دليل التنفيذ: 5–7 خطوات قصوى، خطوات فعلية لا نصائح عامة.
5. لا شيء داخلي يظهر (لا IMG-01 INTERNAL، لا أسماء وكلاء، لا VISUAL DNA كمصطلح ظاهر — النتيجة تظهر لا المخطط).
