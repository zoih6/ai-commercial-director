# FRAMEWORK — BIG IDEA (الفكرة الكبرى والاستعارة البصرية)

## المعادلة

```
حقيقة المنتج (من PRODUCT TRUTH)
+
وعد عاطفي (من STRATEGY NOTE)
+
استعارة غير متوقعة (من هنا)
=
فكرة كبرى قابلة للتوليد
```

## منحنى الطاقة القياسي (Narrative Energy Curve)

كل إعلان يمشي على هذا الشكل مع تكييف المدات:

```
HOOK        إيقاف التمرير — غموض/صدمة/قرب مفرط
   ↓
CURIOSITY   المشاهد يسأل "شو هذا؟"
   ↓
REVEAL      أول ظهور كامل للمنتج — لحظة مهيبة
   ↓
ESCALATION  تصاعد: خامات → تحول → عالم
   ↓
PAYOFF      الذروة / المفاجأة (The Turn)
   ↓
BRAND MEMORY هدوء + Hero Shot + إطار لا يُنسى
```

## جدول الترجمة: شعور ← صورة

| الشعور | الترجمة البصرية |
|---|---|
| غموض | ظلام + كشف جزئي + انعكاسات لا تُفهم |
| انجذاب | الكاميرا تنجذب نحو الشيء ببطء |
| قوة | قطع سريع + انتقالات حادة + زوايا منخفضة |
| رغبة | ماكرو + خامات دقيقة + ضوء غالي |
| دهشة | تحول غير متوقع في منتصف المشهد |
| انتعاش | رذاذ + انفجار ضوء + تشبع عالٍ |
| دفء | ضوء كهرماني + حركة سائلة بطيئة |
| فخامة | مساحة سلبية + إيقاع بطيء + أسود عميق |
| نظافة | أبيض + ضوء منتشر + زجاج |
| طفولة/مرح | ألوان مسطحة زاهية + حركة نطاطة |

## قواعد الهوك

1. أول ثانية تبيع "الاستمرار" لا المنتج.
2. أفضل الهوكات تسأل سؤالًا بصريًا لا يُعرف جوابه إلا بالمتابعة.
3. ممنوع البدء بلقطة منتج كاملة مريحة — إلا في هوك "القرب المفرط" من خامة مذهلة.
4. الهوك يتحقق بالكاميرا والضوء والغموض — لا بالحركة العشوائية.

## قواعد الاستعارة البصرية

1. الاستعارة تنبع من خاصية حسية حقيقية للمنتج (رائحة، ملمس، طعم، فائدة) — لا زخرفة عشوائية.
2. لها TRIGGER واضح: رشّة، قطرة، فتح غطاء، لمسة ضوء.
3. لها سلسلة تصاعد: `صغير ← أكبر ← عالم` (قطرة ← موجة ← أزهار ← عالم).
4. واحدة فقط لكل إعلان — تعدد الاستعارات يشتت ويكسر النماذج.

## مولّد الأفكار السريع

عند توليد الأفكار الثلاث اسأل عن كل فكرة:
1. ما الشيء الذي **لا يتوقع** المشاهد رؤيته هنا؟
2. ماذا لو كان المنتج **سبب** حدوث الشيء لا مجرد موضوعه؟
3. ماذا لو بدأنا من **النهاية** أو من **أثر** المنتج بدل المنتج؟
4. ماذا لو صغّرنا العالم أو كبّرناه حول المنتج؟
5. ماذا لو تحولت مادة من بيئة المنتج إلى شيء آخر تمامًا (Match Cut المركزي)؟

## قاعدة الاختيار النهائي

الفكرة الفائزة هي التي تجمع: مفاجأة بصرية + قابلية تنفيذ توليدي (بلا وجوه معقدة/نصوص/فيزياء مستحيلة) + خدمة صريحة للرسالة الواحدة.
