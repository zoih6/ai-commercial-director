# FRAMEWORK — SHOT ARCHITECTURE (هندسة اللقطات)

مرجع film-director. يحول المفهوم إلى بنية زمنية قابلة للتنفيذ توليديًا.

## بند اللقطة الستة (إجباري لكل لقطة)

```
1. PURPOSE      الهدف الواحد — لماذا هذه اللقطة موجودة؟
2. COMPOSITION  التكوين — أين المنتج؟ حجمه؟ ما حوله؟
3. CAMERA       الكاميرا — حركة واحدة محددة
4. ACTION       الفعل — ما الذي يحدث داخل اللقطة؟
5. LIGHT        الضوء — من VISUAL DNA
6. TRANSITION   الانتقال — كيف نخرج منها ولماذا بصريًا؟
```

لقطة بلا هدف تُحذف. لقطة بحركتين تُقسم. لقطة بلا انتقال تكسر الوصل.

## الجداول الزمنية النموذجية

### 15 ثانية (القياسي)

| الوقت | المشهد | الوظيفة |
|---|---|---|
| 0–2 | هوك الغموض | إيقاف التمرير |
| 2–3 | الكشف | صدمة أولى |
| 3–6 | ماكرو رغبة (خامتين–ثلاث) | انجذاب |
| 6–8 | الـ Trigger + التحول | المفاجأة |
| 8–11 | التصاعد | طاقة تصعد |
| 11–13 | مونتاج الذروة | ذروة |
| 13–15 | Hero Shot | ذاكرة |

### 30 ثانية (القصة الموسعة)

هوك أطول (3 ثوانٍ) + لحظة إنسانية/سياق استخدام (5–8 ثوانٍ) + نفس الهيكل موسعًا.

### 8 ثوانٍ (السريع)

هوك (0–2) + كشف (2–4) + ذروة/تحول (4–6) + Hero (6–8).

## قواعد التصاعد (Visual Escalation)

1. كل مشهد أكبر أو أقوى أو أعمق من سابقه — بلا استثناء حتى الذروة.
2. سلسلة التصاعد المرجعية: `تفصيلة ← عنصر ← مشهد ← عالم`.
3. بعد الذروة: هبوط حاد إلى الهدوء — الـ Hero Shot هادئ دائمًا.

## قاعدة حضور المنتج

- المنتج يظهر مباشرة أو بأثره الواضح كل 3 ثوانٍ كحد أقصى.
- "أثره الواضح" = انعكاسه، لونه، موجة تحوله، ضوؤه — ليس مجرد استمرار المشهد.

## قواعد الانتقالات

1. كل انتقال سبب بصري: شكل مشترك (Match Cut)، لون مشترك، ضوء يغطي العدسة، سائل يملأ الإطار.
2. نهاية كل مشهد موصوفة بحالة تسمح ببداية المشهد التالي (للـ End Frame).
3. ممنوع "التلاشي العام" كحل للانتقال — إن لم تجد سببًا بصريًا، اقطع ببساطة على ضربة إيقاع.

## قواعد خاصة بالتوليد التلقائي

1. مشهد = 2–5 ثوانٍ = برومبت واحد = فعل واحد + حركة كاميرا واحدة.
2. لا مشهد يحتاج ذاكرة من مشهد آخر: كل برومبت يصف حالته كاملة (بمساعدة الإطار الابتدائي).
3. العناصر المعقدة (وجوه، أيدي، كتابة، تشابك أجسام) تُستبدل أو تُدار بعيدًا.
4. الفيزياء المبالغ فيها (انفجارات واقعية، سوائل معقدة تتلاعب بالملاعق) تُبسط إلى بدائل بصرية جميلة (موجات ضوء، جسيمات).

## Hero Shot النهائي (مواصفات ثابتة)

- المنتج مركزيًا، متماسك، بلا منافسة بصرية.
- كل ما صنعه الإعلان من عالم يهدأ خلفه أو حوله.
- حركة كاميرا واحدة: سحب بطيء للخلف أو ثبات تقريبًا.
- ضوء "الذاكرة": أفضل إضاءة في الإعلان كله محفوظة لهذه اللقطة.
