# FRAMEWORK — VISUAL LANGUAGE (القاموس البصري)

مرجع art-director ومهندسا البرومبتات. استخدم المفردات هنا كما هي — **التكرار الحرفي للمفردات بين البرومبتات هو سر ثبات الهوية في النماذج.**

## 1. الألوان (Color)

| النية | الوصف الجاهز |
|---|---|
| فخامة داكنة | "خلفية سوداء عميق بسطح عاكس" |
| نقاء/عناية | "أبيض نقي مع ظلال ناعمة" |
| دفء | "درجات كهرمانية وعسلية دافئة" |
| انتعاش | "أبيض بارد مع لمسات خضراء/زرقاء مشبعة" |
| غموض | "رمادي دخاني مع تدرجات داكنة" |
| ذروة/طاقة | "انفجار لوني بلمسة لون تمييز واحدة" |

قاعدة: أساسي + ثانوي + لون تمييز واحد. لون التمييز يُحفظ للذروة.

## 2. الخامات (Materials)

| الخامة | كيف يصفها البرومبت |
|---|---|
| زجاج سميك | "زجاج ثقيل شفاف تعبره انعكاسات داخلية" |
| سائل عطري | "سائل بلون [X] يتحرك ببطء داخل الزجاجة" |
| معدن | "سطح معدني مصقول يلتقط خط ضوء رفيع" |
| ماء | "قطرات معلقة تتوهج مع الضوء الخلفي" |
| زهور | "بتلات شفافة تطفو في الهواء بحركة بطيئة" |
| دخان | "طبقة دخان رقيقة تتحرك ببطء خلف المنتج" |
| حرير/قماش | "قماش ينساب ببطء شديد كأنه في انعدام جاذبية" |
| جليد/برودة | "سطح متبلور بالصقيع يلتقط ضوءًا أزرق" |

## 3. الضوء (Lighting)

| النوع | الوصف الجاهز | الاستخدام |
|---|---|---|
| حافّ رفيع | "ضوء حافّ رفيع يرسم حدود المنتج من الخلف" | التمييز عن الخلفية الداكنة |
| اتجاهي حاد | "ضوء اتجاهي حاد يلقي ظلالًا طويلة" | دراما |
| منتشر ناعم | "ضوء استوديو ناعم منتشر بلا ظلال قاسية" | نظافة/عناية |
| حجمي | "أشعة ضوء حجمية تعبر غبارًا ذهبيًا مضيئًا" | عوالم/ذروة |
| عملي | "مصادر ضوء داخل المشهد: شموع/شاشات/أضواء مدينة" | واقعية |
| شعاع كاشف | "شعاع ضيق وحيد يعبر الظلام ويكشف المشهد" | هوك/كشف |

## 4. الكاميرا والعدسات (Camera & Lens)

| الحركة | الوصف الجاهز |
|---|---|
| دفع بطيء | "الكاميرا تتقدم ببطء شديد نحو المنتج" |
| دوران مداري | "الكاميرا تدور حول المنتج دورانًا بطيئًا متحكمًا به" |
| سحب للخلف | "الكاميرا تنسحب للخلف ببطء كاشفة المشهد كاملًا" |
| ماكرو منزلق | "الكاميرا تنزلق فوق سطح الخامة بجوار شديد" |
| منخفضة | "زاوية منخفضة تمنح المنتج حضورًا طوليًا مهيبًا" |
| تعليق | "الكاميرا تطفو بثبات مع حركة عائمة خفيفة" |
| تتبع جانبي | "الكاميرا تتبع العنصر جانبيًا بإيقاع ثابت" |

عدسات: "عدسة ماكرو 100mm" للتفاصيل — "عدسة 50mm سينمائية" للإطارات العامة — "عدسة واسعة" للعوالم.

قاعدة ذهبية: **حركة كاميرا واحدة لكل مشهد.**

## 5. الحركة داخل المشهد (Motion)

| الشخصية | الوصف الجاهز |
|---|---|
| مهيبة | "كل الحركات بطيئة وواثقة كأن الزمن أبطأ" |
| انفجارية | "الطاقة تنفجر: عناصر تتسارع للخارج" |
| عضوية | "نمو بطيء: الأزهار تتفتح وتتمايل كأنها حية" |
| سائلة | "حركة انسياب متواصل كسائل" |
| محسوبة | "حركة هندسية دقيقة كآلة فاخرة" |

## 6. المونتاج (Editing)

| الأسلوب | متى | وصفه في المونتاج |
|---|---|---|
| سينما بطيئة | فخامة راقية | لقطات 3–5 ثوانٍ وتنفس بينها |
| إيديتوريال سريع | طاقة/شبابي | قطع 0.3–0.7 ثانية على ضربات الإيقاع |
| فخامة مينيمال | علامات راقية | 4–5 لقطات فقط في الإعلان كله |
| سيريالي | أفكار استعارية | تحولات غير منطقية لكنها متصلة شكليًا |

## قواعد استخدام القاموس

1. اختر من كل محور خيارًا واحدًا مسيطرًا وثبّته في VISUAL DNA.
2. انسخ العبارات الجاهزة حرفيًا إلى البرومبتات — لا تعيد صياغتها في كل مرة.
3. التطور المسموح الوحيد: تطور واحد مقصود عبر الإعلان (ظلام ← نور، هدوء ← انفجار).
